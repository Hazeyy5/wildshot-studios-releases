# Wildshot Studios — installateurs

Application Windows pour créer des slots de casino destinées à Engine, avec des agents IA.

## Installer

1. Ouvre la dernière version dans [Releases](https://github.com/Hazeyy5/wildshot-studios-releases/releases/latest).
2. Télécharge **Wildshot Studios_…_x64-setup.exe** et lance-le (pas besoin d'admin).
3. Les versions suivantes s'installent ensuite depuis l'app.

Windows 10/11 avec WebView2 (déjà présent sur la plupart des machines).

Ce dépôt ne contient que les installateurs. Le code de l'application est privé.
